## Cara Menerapkan Perubahan Ini

Jika kamu setuju dengan usulan perubahan ini (atau ingin menyesuaikan beberapa kata terlebih dahulu):

1. Buka dan edit file terjemahan utama di: `sources/i18n/translations.js`
2. Cari block `id: { ... }` (di baris `260` ke bawah).
3. Timpa nilai dari key-key di atas dengan nilai usulan baru dari dokumen ini.
4. Simpan berkas, dan server Vite akan langsung memuat ulang otomatis (*hot-reload*).
